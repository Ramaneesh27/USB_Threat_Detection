Settings


    

      

        
Start with Windows

        

          Launches USB Threat Analyzer automatically when you log in to Windows,
          so USB devices are monitored from startup. This is optional and
          entirely under your control.
        

      

    


    

    

      Status:
      Disabled
    


    

      
    


    

      Technical details
      

        This writes a single REG_SZ value named USBThreatAnalyzer under
        HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run,
        pointing at this application's own executable path. No administrator
        rights are required or requested. Unchecking and applying removes
        only this one value; nothing else in the registry is touched.

Background mode


    

      

        
Run persistently in the system tray

        

          Keeps USB Threat Analyzer running after you minimize or close the window, like OneDrive.
          It disappears from the taskbar and stays as a hidden icon in the Windows system tray;
          click the icon once to bring the window back. When a USB drive is inserted the window
          pops up on its own and shows the scan. This is off until you allow it here.

Keyboard protection (BadUSB)

    

      Any keyboard plugged in while the app is running is watched. One that types faster than
      100 words per minute is treated as a rogue device
      (a Rubber Ducky-style attack), keyboard input is briefly locked down, and the device is
      disabled when the app runs as Administrator.
